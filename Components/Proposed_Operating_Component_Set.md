# D1-CMP-SET-001 — Complete proposed operating component set

Revision 0 · 2026-09-15  
Status: **SUPERSEDED HISTORICAL PROPOSAL / NOT PHASE 1 BASELINE / NOT PROCUREMENT-RELEASED**

This file preserves the 2026-09-15 mixed ISISPACE/GomSpace proposal and its
evidence gaps. D1-TRD-ARCH-001 subsequently rejected that combination as the
design-development baseline. The active design is controlled by
`Components/design_baseline/README.md` and `COMPLETENESS_MATRIX.md`.

## Decision

The smallest currently supportable Degen-1 operating architecture comprises 19
flight-hardware lines and 10 ground-segment lines. It retains the documented 1U,
uncontrolled-attitude imaging concept and adds the integration and ground items
that the original major-board BOM omitted.

This proposal does **not** meet the Phase 1 evidence requirement as a set. No row
is marked `PHASE 1 BASELINE`. The project cannot truthfully state that a complete
requirements-compliant, publicly verifiable set has been found. The value of this
document is that every required physical function now has either:

- a named COTS candidate;
- an explicit project custom-component identifier; or
- `NO COMPLIANT PART IDENTIFIED`.

The sortable controlled detail is
`Components/Proposed_Operating_Component_Set.csv`, generated by
`Components/generate_proposed_operating_set.py`.

The architecture intentionally has no propulsion, reaction wheels, GNSS
receiver, deployable solar array or precision-pointing subsystem. A3200 rate
sensing supports image-timing/tumble screening; it does not provide pointing.
Ground-derived orbit data and opportunistic imaging satisfy the current mission
concept only if later analysis and testing demonstrate an adequate image
opportunity.

## Functional architecture

```text
6 fixed panel configurations
        -> ICEPS2 Type A + integrated battery
        -> three physical separation/inhibit paths + RBF
        -> D1-IF-001 protected 3.3 V OBC branch -> A3200
        -> D1-IF-001 protected 3.3 V radio branch -> AX100-U
        -> switched 3.3 V payload branch -> piCAM/FM -> UART -> A3200
        -> switched 5 V deployment branch -> AntS

A3200 <-> CAN/CSP <-> AX100-U -> D1-RF-001 -> AntS
A3200 <-> I2C <-> ICEPS2
A3200 <-> isolated I2C <-> AntS

AntS <-> M2 436CP42UG + rotator/feed/filter chain
      <-> ground AX100-U/DMC-3 <-> station computer
      -> reconstructed image -> printer
```

## Preliminary resource effect

Substituting piCAM/FM's documented 40 g for the old 50 g CS-101 allocation makes
the flight-set planning mass 1,053.5 g before growth, or 1,264.2 g with a uniform
20% growth factor. This is a bookkeeping calculation, not a CAD mass or measured
mass. It remains below the project's 1,330 g target on paper.

The same substitution changes the existing hardware planning midpoint from
EUR 46,500 to EUR 45,450. This is not a quote and excludes the incomplete ground
chain, engineering/prototype hardware, tests, licensing, launch and integration.
No procurement baseline is changed by this calculation.

## Gate result and next action

The proposal is functionally complete as a list but fails G1 because its evidence
and custom designs are incomplete. The first closure package remains FLT-001 and
FLT-002: structure, rails, exact separation-switch hardware and RBF/source
isolation. Until that package passes, the mechanical foundation and launch-safety
architecture are not fixed.

Do not promote this document by deleting the gaps. Close them with exact public
evidence or record the point where later supplier evidence, professional review or
physical test becomes necessary.
