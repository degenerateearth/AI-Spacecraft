# D1-COM-001 - UHF command, telemetry and image radio

Revision A - 2026-09-16  
State: **CUSTOM/TO BE VERIFIED - exact RF module selected; carrier, waveform release and link closure open**

## Selection

Degen-1 selects one Chengdu Ebyte **`E22-400M22S`** SPI radio module on a
project-designed carrier. The module is based on Semtech `SX1268`, includes the
32 MHz TCXO and RF switch, and is sold by its manufacturer. It replaces the
earlier ADDNICS candidate for the detailed-design baseline.

The ADDNICS `ADD1397B` Rev. C ICD remains valuable heritage evidence but is not
the selected part: the public ICD leaves mass blank, the current BIRDS record
names `ADD1397CF`, and the ADDNICS public product page does not identify the
orderable configuration. Those conflicts prevent an auditable exact selection.

## Module pin use

| Module pins | Signal | Degen-1 use |
|---:|---|---|
| 1-5, 10-12, 20, 22 | `GND` | uninterrupted RF/digital ground plane and carrier bonding |
| 6 | `RXEN` | OBC-controlled RF receive switch, defined low at reset |
| 7 | `TXEN` | driven by SX1268 `DIO2` as recommended; test point provided |
| 8 | `DIO2` | RF-switch transmit control |
| 9 | `VCC` | protected `+3V3_RF`; local ceramic bulk/high-frequency decoupling |
| 13 | `DIO1` | packet/timeout interrupt to OBC |
| 14 | `BUSY` | busy input to OBC; every SPI transaction waits for deassertion |
| 15 | `NRST` | supervised active-low reset from OBC |
| 16-19 | `MISO`, `MOSI`, `SCK`, `NSS` | dedicated 3.3 V SPI bus |
| 21 | `ANT` | controlled-impedance 50 ohm trace to the selected RF connector/filter/antenna assembly |

The module is a radio transceiver, not a modem with a private host protocol. The
OBC issues the public SX1268 SPI commands and implements all Degen-1 packet,
authentication, retry, image-segmentation and Doppler scheduling behavior.

## Power and fault containment

A second TI `TPS2553DRVR-1` on D1-EPS-001 supplies `+3V3_RF`. Its latch-off
response prevents an overcurrented module from repeatedly loading the bus. The
exact `R_ILIM` shall be calculated from the TI limits with the module's 105 mA
maximum transmit current, carrier consumption, capacitor charging and converter
fault limits. The radio defaults unpowered after reset and after any watchdog or
brownout event.

The module is commanded to standby before its supply is removed. The carrier
shall prevent SPI/control pins from back-powering an unpowered module.

## Provisional link definition

The design uses a half-duplex UHF amateur-satellite link. Frequencies are
configuration parameters and cannot be finalized until IARU coordination and
FCC authorization. Analysis shall use 435.8 MHz uplink and 437.4 MHz downlink as
explicit planning frequencies; these are not assignments or authorization to
transmit.

The waveform trade is constrained to modes the selected module implements from
public commands. Revision A carries LoRa and GFSK as analysis candidates. The
released choice must close:

- 500 km nominal and 2500 km conservative slant-range budgets;
- maximum LEO Doppler and TCXO error without relying on an unavailable private
  synchronization feature;
- occupied bandwidth and applicable amateur-satellite coordination limits;
- time-on-air for health telemetry, command acknowledgement and a representative
  piCAM image;
- receiver sensitivity at the exact selected bitrate/bandwidth; and
- at least 3 dB calculated implementation margin before the physical-test phase.

No earlier AX.25/4800-bps link result transfers to this radio.

## Degen-1 application frame

The application layer shall be public and implemented identically in flight and
ground software. Each variable-length packet contains, in order:

1. protocol version and packet type;
2. spacecraft identifier;
3. monotonically increasing 32-bit sequence number;
4. mission-time field;
5. payload length and payload;
6. CRC-32 over the application header and payload; and
7. for uplink commands, an AES-128-CMAC authentication tag and persistent replay
   check.

Command payload remains intelligible; authentication is not represented as
regulatory permission to encrypt amateur traffic. Tag length, byte order,
polynomial, exact field widths, key loading and lost-state recovery must be fixed
in the released wire-protocol document and test vectors. Critical commands
include acknowledgement and persistent execution result. Radio-disable commands
survive OBC reset.

Image data is segmented by image identifier, fragment number, total fragments and
byte offset. Ground software writes a JPEG only after length, CRC and JPEG
start/end-marker validation; missing fragments can be requested again.

## Custom carrier release requirements

1. KiCad schematic, PCB, fabrication files and exact BOM for the module carrier.
2. Manufacturer footprint transfer and courtyard, including module thickness.
3. Controlled-impedance stack-up, RF launch, connector, filter and coax schedule.
4. Input protection, local decoupling, load-switch and digital back-power analysis.
5. RF enclosure/keep-out and conducted/radiated EMC provisions.
6. SX1268 initialization register/command table and public flight/ground driver.
7. Complete wire protocol with golden test vectors and fault cases.
8. Link, Doppler, time-on-air and duty-cycle calculations.
9. Conducted power, harmonics, sensitivity, packet-error-rate, thermal-vacuum and
   end-to-end ground-link verification procedures for the later physical phase.

## Evidence limits

The module is industrial COTS and is not documented as radiation hardened,
vacuum qualified or launch qualified. The Ebyte manual does not provide orbital
radiation, outgassing, random-vibration or thermal-vacuum evidence. Selection for
this education-grade theoretical design depends on fault containment, a defined
physical verification program and later expert RF review; it is not a claim of
flight readiness.
