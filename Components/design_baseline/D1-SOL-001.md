# D1-SOL-001 - body-mounted solar panels

Revision A - 2026-09-16  
State: **CUSTOM/TO BE VERIFIED - exact cell assembly and five-face topology selected; panel PCB release open**

## Exact cell assembly

Each Degen-1 solar panel uses two series-connected AZUR SPACE
**3G30A-Advanced 4x8 SCA/CIC, material part number `81442`, drawing
`ZP-0004289`**. The selected assembly includes the 3G30C triple-junction cell,
corner-mounted silicon bypass diode, welded out-of-plane silver-coated Kovar
interconnects, 100 micrometre AR-coated coverglass and space-grade adhesive.

The bare-cell part `81441` is not interchangeable because it omits the selected
coverglass, diode and interconnect assembly.

## Derived string values

At the manufacturer's 28 degree C AM0 condition, one two-cell BOL series string
has typical:

- `Vmp = 2 x 2.411 = 4.822 V`;
- `Imp = 0.499 A`; and
- `Pmp = 2.406 W`.

At the published 1E15 electron-fluence column, the corresponding typical string
value is `2 x 2.230 V x 0.480 A = 2.141 W`. Five simultaneously normal-incident
faces are physically impossible and their powers may not be summed as an orbital
average. Attitude, eclipse, temperature, Earth albedo, wiring, diode, converter,
contamination and mismatch losses belong in the reproducible orbit-energy model.

At 100 degrees C, applying the published 1E15 `Vmp` coefficient from 28 degrees C
gives a screening value of approximately `2 x (2.230 - 0.0072 x 72) = 3.423 V`
per string. This remains above the LTC3119 2.5 V input minimum, but it is a
calculation from typical cell data and does not replace a worst-case panel curve.

## Panel circuit and interface

Each panel contains:

1. two exact `81442` SCAs in series using the supplied Kovar interconnects;
2. one Nexperia `PMEG4010CEJ-QX` 40 V, 1 A Schottky series-isolation diode;
3. one YAGEO Nexensos M222 `32208571` Pt1000 Class F 0.3 sensor with two
   independent leads; a four-wire panel connection carries string positive,
   string return, `RTD_HI` and `RTD_RET`; and
4. exposed test pads for string open-circuit voltage and RTD continuity.

The exact RTD is a **YAGEO Nexensos `32208571`**, M222 thin-film Pt1000,
Tolerance Class F 0.3 (B), TCR 3850 ppm/K. Manufacturer document
`20002220968`, Part 001, Version 03 (11/2024) establishes a
2.3 +0.2/-0.1 x 2.10 +/-0.2 x 0.9 +0.3/-0.2 mm body, 10 +/-1 mm by
0.2 +/-0.02 mm platinum-clad nickel leads, -70 to +500 degrees C class range,
0.1--0.3 mA measuring current, and welding/crimping/brazing connection methods.
The body-to-panel attachment, lead transition, strain relief and readout circuit
remain custom design work. No panel temperature accuracy is credited until
attachment gradients, lead resistance, ADC/reference accuracy, self-heating and
calibration are analyzed and verified.

Five isolated positive outputs join only at the D1-EPS-001 input. Returns join
at the EPS star point. A shadowed or failed panel therefore cannot directly sink
the other strings through its SCA path.

The final EPS MPPC set point must use a worst-case string curve. It is not frozen
from the typical 28 degree C value.

## Evidence limits

The SCA data are typical population values, not delivered-lot guaranteed IV
curves. The manufacturer provides the detailed drawing/STEP and mission-specific
performance by request. YAGEO explicitly does not recommend its standard
catalogue products for aerospace applications; the selected RTD therefore
requires project-level radiation, vacuum/outgassing, thermal-cycle, vibration,
attachment and calibration verification and is not represented as space
qualified. Final cell procurement, supplier-approved assembly process,
delivered-lot flash data and acceptance testing are downstream. The present
record supports a theoretical panel design; it does not establish the finished
panel's output, temperature accuracy, mechanical strength or environmental
qualification.
