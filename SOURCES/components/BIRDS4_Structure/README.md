# BIRDS-4 structure reference

Retrieved 2026-09-16 from the official `BIRDSOpenSource/BIRDS4-CAD`
repository at commit `3bab47a0f53410ef79005d21321ff659726f0a1c`.

This retained MIT-licensed subset contains the full flight-model STEP assembly,
the eleven unique frame-part STEP files used by that assembly, the upstream
README and the upstream license. The geometry is reference evidence and a
starting point for a Degen-1 derivative. It is not a Degen-1 released drawing,
material certificate, tolerance specification or structural qualification.

Upstream: https://github.com/BIRDSOpenSource/BIRDS4-CAD

The reproducible extraction script and its output are in
`drawings/freecad/structure_reference/`.
