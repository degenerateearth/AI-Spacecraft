# K&J Magnetics D84 source custody

Retrieved 2026-09-16 from K&J Magnetics' current `D84` product page and its
public download forms. The local archive contains the manufacturer product page,
drawing, generated specification, generated certificate of compliance and STEP
model. Copyright permission for redistribution was not established, so the
HTML/PDF files remain local-only; the small STEP model is also kept local-only
pending a license determination. Official URLs and hashes are public in the
archive manifest.

The certificate is a manufacturer product-family declaration. It is not a lot
certificate or acceptance record for a future Degen-1 unit.
